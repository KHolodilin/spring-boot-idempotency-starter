# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.x (latest release) | ✅ |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, use one of the following channels:

- [GitHub private vulnerability reporting](https://github.com/KHolodilin/spring-boot-idempotency-starter/security/advisories/new) (preferred)
- Email: kholodilin.valerii@gmail.com

Include as much of the following as you can:

- Affected version(s)
- A description of the vulnerability and its impact
- Steps to reproduce or a proof of concept

You can expect an acknowledgement within a few days. Once the issue is confirmed,
a fix will be prepared and released, after which the vulnerability will be disclosed
in the release notes.
